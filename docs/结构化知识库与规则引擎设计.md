# 结构化知识库与规则引擎设计（v0.1 草案）

> 目标：文档生成从"LLM 自由撰写（5-10 分钟、数值可能编造）"改为
> "**本地规则引擎确定性计算（秒级）+ LLM 仅润色成文（30 秒内）**"。
> 识别、判定、选型、核算全部由本地代码完成，LLM 不参与任何数值与结构决策。

## 一、16 键结构化知识库

每条维修案例/方案在现有知识库（标题+标签+全文检索）之外，增加一张**结构化方案表**：

| # | 键 | 说明 | 示例 |
|---|---|---|---|
| 1 | defect_type | 缺陷类型（词典枚举） | 夹芯损伤 / 分层 / 雷击损伤 / 导线断裂 / 涂层损伤 / 开裂 / 风机罩损伤 |
| 2 | defect_position | 损伤部位 | 前缘 / 后缘 / 壳体 / 梁帽 / 腹板 / 叶根 / 人孔 |
| 3 | workface | 作业面 | internal / external |
| 4 | grade | 适用损伤等级 | A / B / C / D / E（可多选） |
| 5 | scheme_code | 修复方案编码 | RS-STR-04 |
| 6 | scheme_name | 方案名称 | 夹芯真空灌注修复 |
| 7 | steps | 工序列表（有序，每步含名称/工具/工艺参数） | 打磨→铺层→真空灌注→固化… |
| 8 | materials | 物料清单（名/规格/单位/单耗公式） | 玻纤布 E800、树脂、真空袋膜… |
| 9 | area_formula | 面积/用量核算公式 | 玻纤布面积 = 损伤面积 × 层数 × 1.30 |
| 10 | team | 班组配置 | external:4人 / internal:3人 |
| 11 | duration_hours | 工期（小时，可按工序分解） | 26h |
| 12 | quality_std | 质量检验标准 | 巴氏硬度≥60HBa、电阻≤50mΩ、保压测试… |
| 13 | risk_notes | 风险管控要点 | 高空作业、树脂配比时限… |
| 14 | accept_criteria | 验收与作业条件 | 温度≥15℃、湿度≤70%… |
| 15 | source_refs | 来源案例（知识库条目 id 列表，可溯源） | ["img_…", "case_…"] |
| 16 | images | 关联施工图（文件路径+题注） | [(path, "图2-1 打磨开窗示意")] |

**存储**：`%AppData%/叶片缺陷审核/repair_schemes.json`（与 knowledge_base.json 并列）。
**来源**：从现有 63 份案例 PDF + 图片知识库，用当前 LLM **离线批量抽取一次**（抽取结果人工可改，之后生成不再依赖 LLM 判断）。

## 二、本地规则引擎管线（全确定性，代码实现）

```
用户输入缺陷描述
  ↓ ① 识别（关键词词典 + 正则）
  缺陷类型 / 部位 / 作业面 / 量化参数（面积、层数、导线根数…）
  未识别的字段 → 弹窗让用户补选（下拉框，不靠 LLM 猜）
  ↓ ② 判定（等级规则表，本地）
  grade：面积/深度/部位 → A~E
  ↓ ③ 选型（scheme 映射表：defect_type × position × workface × grade）
  命中 repair_schemes.json 中的唯一方案（多命中让用户选）
  ↓ ④ 核算（公式引擎，本地）
  玻纤布面积×层数×1.30、薄膜≥1.0㎡、班组人数、工时求和 → 物料表/工期表
  ↓ ⑤ 组装（模板填充）
  标准章节树 → 每节填入结构化数据 → 结构化草稿（含全部数值/表格/图片位）
  ↓ ⑥ LLM 仅润色（唯一 LLM 调用）
  输入：结构化草稿；指令：只改写表述使其成为正式工程文档语言，
  严禁改动任何数值、序号、章节结构、物料表（prompt 强约束 + 程序校验回读数值）
  输出：最终 HTML → 现有 DocxBuilder 生成 .docx
```

**耗时预期**：①-⑤ 本地毫秒级；⑥ LLM 输入是结构化草稿（比自由撰写短 60%+）、
输出token 相近但无需"思考"内容 → 撰写环节从 5-10 分钟降至 **30-60 秒**，
且数值零编造（程序在润色后回读关键数值做一致性校验，不一致自动回退草稿）。

## 三、界面变化（文档生成页）

- 缺陷描述输入框保留；下方自动出现**识别结果面板**（缺陷类型/部位/作业面/等级/面积下拉与数字框，识别失败项高亮提示补充）
- 生成按钮 → "生成文档（规则引擎）"；润色失败仍可导出草稿版
- 新增"方案库管理"入口（一期可暂缓：直接改 JSON）
